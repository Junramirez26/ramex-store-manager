# RAMEX Store Manager

RAMEX Store Manager is a desktop application developed in Python for managing inventory, sales, purchases, customers, and business finances.

Initially created for a sports jersey store, the system is being designed with scalability in mind, allowing future adaptation to different types of products and businesses.

## Features

* Inventory and stock management.
* Purchase and sales registration.
* Customer management.
* Income and expense tracking.
* Profitability and earnings monitoring.
* Product categorization.
* Local SQLite database storage.

## Technologies

* Python
* SQLite
* CustomTkinter
* Tkcalendar
* Pandas

## Project Status

🚧 Active development.

The project is continuously evolving with improvements focused on financial management, data validation, reporting, usability, and scalability.

## Objective

To provide a practical and efficient solution for entrepreneurs and small businesses, enabling them to manage their operations, inventory, sales, and finances from a single platform.
